🛡️ Chrome Extension Architecture & Data Flow

Manifest V3 Compliant

BrowserShield-Pro ("Sheilded") operates entirely within Google Chrome without external backends or cloud API dependencies.

1. Main-World Page Hook
Runs in the webpage's main execution context to passively monitor fetch, XMLHttpRequest, and sendBeacon calls without interfering with page scripts.
2. Isolated Content Script
Samples event-loop ticks via requestAnimationFrame, observes DOM churn via MutationObserver, and records visibility changes.
3. Sub-ms JS Inference Engine
Evaluates serialized XGBoost decision trees and Platt logistic calibration in pure JavaScript in < 0.4 ms, generating real-time risk scores and threat attribution.
